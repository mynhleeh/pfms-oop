\subsection{2. Mô tả tổng quan hệ thống}\label{muxf4-tux1ea3-tux1ed5ng-quan-hux1ec7-thux1ed1ng}

\subsubsection{2.1 Bối cảnh hệ thống}\label{bux1ed1i-cux1ea3nh-hux1ec7-thux1ed1ng}

Hệ thống quản lý dữ liệu tài chính của một cá nhân, hỗ trợ nhiều ví,
nhiều loại tài sản và báo cáo tổng hợp. Dữ liệu lưu cục bộ, single-user.

\subsubsection{2.2 Mục tiêu hệ thống (System Goals)}\label{mux1ee5c-tiuxeau-hux1ec7-thux1ed1ng-system-goals}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Quản lý dòng tiền:} ghi chép, phân loại và theo dõi thu/chi
  theo danh mục 3 cấp (type → group → category).
\item
  \textbf{Nắm bắt tình hình tài sản:} tính toán số dư từng ví và tổng
  tài sản theo thời gian thực.
\item
  \textbf{Hỗ trợ ra quyết định:} cung cấp dashboard tổng quan với biểu
  đồ cơ cấu tài sản, thu/chi theo tháng và dòng tiền.
\item
  \textbf{Quản lý mục tiêu tài chính:} theo dõi tiến độ các quỹ mục tiêu
  (khẩn cấp, sức khỏe, mục tiêu, hưu trí).
\item
  \textbf{Đảm bảo độ chính xác tài chính:} mọi phép tính tiền dùng
  \texttt{BigDecimal}, không dùng số thực dấu chấm động.
\end{enumerate}

\subsubsection{2.3 Giả định (Assumptions)}\label{giux1ea3-ux111ux1ecbnh-assumptions}

\begin{itemize}
\tightlist
\item
  Hệ thống là \textbf{single-user}: chỉ có một người dùng là Owner,
  không có đăng nhập/phân quyền.
\item
  Dữ liệu \textbf{lưu cục bộ} (database nhúng, ví dụ H2); không
  đồng bộ lên cloud/đa thiết bị.
\item
  Danh mục phân loại cố định \textbf{3 cấp}: \texttt{type} →
  \texttt{group} → \texttt{category}.
\item
  Mọi số tiền, lãi suất, số dư đều là \texttt{BigDecimal} (2 số thập
  phân).
\item
  Người dùng có thể import dữ liệu từ file Excel nguồn
  \texttt{finance-mng.xlsm} hoặc template CSV.
\item
  Lãi suất tính theo quy ước: tiết kiệm không kỳ hạn = lãi đơn
  \texttt{capital*rate/365}; có kỳ hạn theo số ngày thực gửi; chứng chỉ
  quỹ dùng hàm \texttt{RATE()}.
\end{itemize}

\subsubsection{2.4 Ràng buộc (Constraints)}\label{ruxe0ng-buux1ed9c-constraints}

\begin{itemize}
\tightlist
\item
  \textbf{Nền tảng:} Desktop \textbf{Java 17+} với \textbf{JavaFX}
  (FXML, SceneBuilder); đóng gói \texttt{.exe} bằng \texttt{jpackage}.
\item
  \textbf{Kiến trúc:} phân tầng View (JavaFX/FXML) / Controller / Model
  / Service / Repository; tuân thủ OOP, SOLID.
\item
  Không có yêu cầu đăng nhập, cloud sync, bản Web hoặc bản
  Mobile.
\item
  \textbf{Dữ liệu lịch sử:} hỗ trợ đối chiếu với kết quả của file Excel
  gốc.
\end{itemize}
